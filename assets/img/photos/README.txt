Photos de la page (bandeau, accueil, sections, remerciements).
Par défaut, la page charge les photos depuis Wikimedia Commons. Pour les héberger
avec le site (recommandé : plus rapide, indépendant de Wikimedia), lancer une fois
dans R depuis le dossier enquete-gestion-amp/ :  source("tools/download_photos.R")
Les fichiers sont alors enregistrés ici sous le nom indiqué dans SURVEY.PHOTOS (key.jpg).

Crédits : auteurs et licences (CC BY-SA 2.0 / 3.0 / 4.0) indiqués dans
assets/js/survey-config.js (PHOTOS) et affichés sous chaque photo : ne pas les retirer.
Pour utiliser vos propres photos de terrain, les déposer ici et modifier la liste
PHOTOS dans tools/xlsx_to_config.py (puis relancer le script).
